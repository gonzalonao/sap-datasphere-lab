# Syllabus

Course objectives per unit, in my own words. Add one section per unit before starting it.

## Unit 01 — Space, first model and report, remote source

Exercise: [units/01-space-model-remote](units/01-space-model-remote/README.md)

1. **Space.** Create and configure my own space.
2. **First model and report.**
   - upload CSV file(s) into local tables
   - build my first graphical view
   - build my first story in SAP Analytics Cloud (SAC)
   - learn the basics of the view editor
3. **Remote source and time dimension.**
   - replace a local table with a remote table
   - create a new connection
   - create a time dimension and use it in my story
   - understand associations and how to use them
